## 功能

- **行走**：惯性、奔跑、下蹲、跳跃、楼梯和斜坡；掉进虚空时安全回到地面。
- **物体物理**：群组和组件会根据材质下落、弹跳和翻倒；可以踢、抓取和投掷它们。
- **天空与天气**：按日期、时间和地点显示太阳、月亮和星星；雨、雪、云、雷暴，以及在地面积存的雪。现成的天气情景，以及随天空时间自行变化的多变天气。导出的视频中也有天气。
- **路径**：边走边录制相机，回放，导出为场景或 AVI 视频。可以在模型中移动、旋转它的各个位置来微调（带箭头的球体，箭头长度表示缩放，以及取景框），也可以从零开始创建。在面板中，每条路径都会展开为其位置列表；单击某个位置，或双击它的球体（或按 Enter），会打开其设置并预览它看到的画面；在两个位置之间单击，则用当前视图添加一个位置。回放时列表会高亮当前位置。“精简相机”会把堆叠在一起的球体合并为一个，取它们的平均值（位置、视线、缩放），前提是它们彼此的视线夹角不超过 45°。
- **自主探索者**：相机观察场景，选出最有意义的东西，一边看着它一边朝它迈一步，然后重新开始；最后整个游览会成为一条路径。见下文。
- **照片与相册**：按 P 拍下你看到的画面；探索者会自己拍下游览中最有趣的东西。每条路径都能在浏览器中打开它的相册：桌上的拍立得照片，附有笔记。见下文。
- XInput **游戏手柄**，以及用数字小键盘环顾四周。
- 设置面板支持 36 种语言。
- **无障碍**：*无障碍 › 无闪光* 关闭所有闪光，包括拍照和闪电（见 [ACCESSIBILITY.md](.github/ACCESSIBILITY.md)）。

要求：Windows 上的 SketchUp 2023 或更高版本。在 Mac 上可以安装，但不会启动，并会给出提示。

## 安装

- 通过 SketchUp 的 **Extension Warehouse**（已签名版本），或
- 从 [最新版本](https://github.com/Dagadam/dagawasd/releases/latest) 的 *Assets* 中下载 **`dagawasd-<版本>-warehouse.rbz`**，然后在 *扩展程序 › 扩展程序管理器 › 安装扩展程序* 中安装。另一个文件 `dagawasd-<版本>.rbz` 还包含 Claude Code 桥接（见 *两个安装包*）。

设置保存在 `%APPDATA%\DagaWASD\settings.json`：更新不会删除它们。

## 自主探索者

工具栏中的眼睛按钮（或 *扩展程序 › DagaWASD › 自主探索者*）：一个小窗口让你选择档案（它的性格，见下文）以及是否把游览录制为路径，并记住你的选择供下次使用；用方向键和 Enter，或双击某个档案，即可立即出发。探索时再按同一个按钮即可停止。循环为：**分析 → 选择目标点 → 一边看着它一边朝它迈一步 → 分析**。

- **分析**：一张穿过屏幕网格的射线“视网膜”（`view.pickray` + `model.raytest`）为每个单元给出距离、法线、面、物体和颜色。由此计算显著性：深度边缘、棱边、细节、颜色对比（Lab）、稀有度、人体尺度的组件和群组；大面积的墙和地板权重很低。再按距离、视野中心和新颖度加权。
- **记忆**：视线已经看过的东西的体素、已经走过的地方（平面和高度都记录：楼上仍然算新的），以及针对每个目标和每个类别的厌倦（看过一张沙发后，同样的沙发就不那么吸引它了）：这样它不会总回到同样的东西上。
- **已见区域地图**：步行时，经过身体高度的射线会在一张 50 cm 网格的地图上（每层一张）标出看到的地面及其高度（地板、台阶、家具表面）以及碰到的墙。它有两个用途：
  - **边界**：已看过与从未看过之处的分界（门的另一边、拐角后面）会成为一个目标，即“未探索区域”：它会走过去往里看。它的权重与开阔空间相同，取决于档案中的“想走动”程度；在注意力地图中，它们是地面上的紫色小方块；
  - **路径规划**：对每个目标，它在地图上（A*）规划一条到达能看到目标的位置的路线：绕开墙和家具并保持一点距离，上楼梯（一级一级可以，桌子或沙发不行），沿斜坡上行直到玩家的最大坡度，能直走的地方就直走。在还没看过的地方它保持乐观并尝试前进。每次分析时，它都会在新地图上重新检查剩余路线；如果现在被挡住了，就另找一条；每 3 秒无论如何都会重新规划（也许它看到了捷径）；撞到东西的地方会被标记并重新计算。如果目标消失在某物后面，或者路线偏离了目标，它会看向前进的方向。当前路线是地面上的虚线。搜索和分析一样分片进行。
- **迈步**：朝目标点前进，绕开障碍物，上楼梯，绝不从边缘掉下去；它停在能看到物体全貌的距离并注视它。从鸟瞰视图开始时，它会飞行并降落在有东西可看的地方。
- **绕物体行走**：到达一个物体后，如果档案要求（*绕物体行走*，以度为单位：摄影师 180°，好奇 90°），它会从更开阔的一侧一边看着物体一边绕行，从多个角度观察；如果路被挡住就折返。然后停留。
- **跳跃**：挡住去路、又没有短距离绕行路线的低矮障碍物（矮墙、栅栏、大台阶），如果另一侧有可以落脚的平面，它就会跳过去。它使用玩家的跳跃力和重力（默认值下双脚升高 1.08 m；它会跳过低于该高度 85 % 的东西）；它从不跳到座椅和桌子上。可以在档案中关闭（“缓慢”不跳）。
- **身体**：眼睛高度、半径、台阶（最多 25 cm）、跳跃和重力都与玩家相同（面板 › 玩家），即使在探索过程中修改也会生效。
- **流畅**：与桥接的实时搭建一样，分析是一个 Fiber，在两帧之间分片运行；视网膜会根据该模型中一条射线的开销变密或变疏。启用 *系统 › 性能 › 自适应分析* 后，分析的频率也会跟随空闲的计算能力，在每秒的最小值和最大值之间变化，而不会拖慢行走。
- **操作**：Esc 或单击停止，右键暂停，“寻找别的”，注意力地图，彩色眼睛；滚轮调节速度；I 隐藏或显示左上角的信息行。切换到其他工具会让它停止；用中键环绕会让它暂停，之后它会从你放置相机的地方继续。
- **卡住了？** 如果 10 秒内移动不到 75 cm（在附近的几个目标之间犹豫不决，或被困在角落里），它会在 12 个方向中寻找一条出路并沿着走几秒；如果步行无路可走且模式为自动，它就会起飞。
- **结束时**，如果开始时勾选了“记录路径”，这次游览会成为一条路径（“探索 1”……）：可以在面板中回看，或制作成场景或视频。

### 档案

探索者的性格是一个**档案**，即一组系数：*扩展程序 › DagaWASD › 探索者档案…*，或在探索时右键 › *档案*（即时切换）和 *编辑档案…*。

| 档案 | 性格 |
|---|---|
| 均衡 | 一贯的样子 |
| 好奇 | 很快就会厌倦，寻找细节和稀有的东西，探索得更多，绕物体 90° |
| 跑者 | 3.2 m/s，反应敏捷，停留时间短 |
| 缓慢 | 0.5 m/s，停留时间长，视线转动缓慢 |
| 摄影师 | 靠近之前先放大（缩放）目标，然后走过去并绕行 180° |
| 无忧 | 随性选择，容易改变主意，喜欢开阔空间 |
| 士兵 | 侦察，始终步行：3.6 m/s，从远处短暂观察，优先去还没看过的地方 |

在窗口中，每个系数都有一个滑块（拖动时，如果探索者正在使用该档案，会实时变化）和一个恢复原值的 ↺。分组：移动（速度、停留距离、台阶、步行/飞行）、视线（转动、反应、**视线的连贯** —— 它有多倾向于转向正在看的东西旁边的东西，而不是回到已经转开的东西上）、注意力（停留、绕物体行走、时长、**决心** —— 对刚选定的目标在多少秒内不改变主意 —— 以及**专一**）、好奇心（记忆、厌倦、想走动、随性）、吸引它的东西（物体、轮廓、细节、颜色、稀有度的权重）以及缩放。“新建”会复制正在使用的档案；预设档案可以修改，之后也可以恢复。

在 `settings.json` 中：`"explore_profile"`（正在使用的档案）、`"explore_profiles"`（你自己的档案，以及对预设档案的修改）和 `"explore_record"`（启动窗口中记录路径的复选框）。各项数值分层叠加：默认值（`EX_DEFAULTS`，`lib/explore.rb`）← `"explore": { … }` ← 档案 ← 启动者的选项（桥接）。

开启桥接后，Claude Code 可以控制并观察它（开发工具的命令是意大利语）：

```
ruby tools/esplora.rb avvia --secondi 120 --velocita 1.3   # 启动：120 秒，1.3 m/s
ruby tools/esplora.rb avvia --profilo Fotografo    # 仅本次游览使用的档案
ruby tools/esplora.rb profili                      # 列表；“profilo 名称” 启用该档案
ruby tools/esplora.rb segui --foto esplorazione    # 每个选择输出一行和一张照片
ruby tools/esplora.rb ferma                        # 停止并保存路径
```

### 由 AI 驾驶

使用 `pilota` 和 `guida` 时，由 Claude Code 决定去哪里，而探索者继续自己行走和观察（`lib/expilot.rb`）。每个看到的东西都有一个简短且稳定的名字（`o12` 是物体，`s7` 是面，`F3` 是未探索区域）；AI 把目的地放进日程，探索者用自己的步伐、绕墙的路线和视线依次到达。日程为空时它会重新自己选择：它从不停下来等 AI。

```
ruby tools/esplora.rb pilota                       # 等待一个事件并描述它看到的东西
ruby tools/esplora.rb guida --vai o12 --giro 90 --commento "主祭坛" --vai F3
ruby tools/esplora.rb guida --guarda o7 --per 3    # 转身去看，不移动
ruby tools/esplora.rb guida --piace label:colonna=2 --evita o4
ruby tools/esplora.rb guida --sostituisci --punto 12,4,1.7   # 新日程：一个以米为单位的点
ruby tools/esplora.rb guida --svuota               # 清空日程：重新自己选择
ruby tools/esplora.rb guida --foto                 # 在当前（或下一次）停留时拍照
ruby tools/esplora.rb guida --foto-sempre          # 每次停留都拍照（--foto-mete：只在 AI 的目的地拍，--senza-foto）
```

会唤醒 `pilota` 的事件：到达目的地、完成目的地（或放弃，以及原因）、日程快空或已空、无法到达的目的地、从未见过的显著事物、一张照片。

**步行：能到哪里。** 步行时，描述会根据探索者观察所建的地图，为每个东西和未探索区域说明能否到达（`reach`：能、也许要经过未见过的区域、不能）以及需要走多少米（`walk_m`）。指向步行无法到达之物的“去”会被立即拒绝并说明原因；照片中这些东西带浅灰色标签。在 Stromboli 模型上，自主驾驶从大约每分钟到达一个目的地提高到了三个。

**带标注的照片。** 在 AI 的目的地前停留时，探索者会静止并注视目的地，拍下一张视图图像（800 px），并在每个可见的东西旁写上它的短名称：目的地为黄色，物体为蓝色，面为灰色，未探索区域为紫色。这样 AI 就能看到“Group2577#2”之类到底是什么，并用名字指代它们。照片保存在 `%APPDATA%\DagaWASD\pilota`（最近 40 张）。拍一张照片会让 SketchUp 卡住一张视图图像的时间（大模型上约半秒）：所以只在静止时拍。

桥接接口：`GET /explore/percept?since=N`（描述和事件）、`GET /explore/wait?since=N&timeout=60`（同样的描述，但桥接只在有唤醒事件时才回应：`pilota` 不会不停轮询），以及带 `{"cmd": "steer", …}` 的 `POST /explore`。

**视频中的评论。** AI 说的话（`--commento`、`--di`，或 steer 中的 `say`）会保存在录制的路径中，位于它说话的那一刻：制作场景时成为最近场景的描述，并在视频旁生成 `.srt` 字幕文件（AVI：同名，播放器会自动打开；PNG 图像：`crea_video.bat` 会把它放进 MP4）。

**自主驾驶。** `tools/pilota_ia.rb` 会自行驾驶，无需逐条下令：它等待桥接的事件，把描述和停留时的照片发给 Claude，再把 Claude 的决定传给桥接。默认引擎是 Claude Code 本身（`claude -p`，使用这台电脑的账户：不需要密钥）；设置了 `ANTHROPIC_API_KEY` 时则使用 Claude API（`anthropic` gem）。在 Stromboli 上一轮需要 4–5 秒。每一轮都有消耗：`--turni`（20）和 `--secondi`（300）设定上限，结束时会打印所用的 token 数。

```
ruby tools/esplora.rb avvia --a-piedi                   # 启动，步行
ruby tools/pilota_ia.rb --turni 15 --secondi 240        # 低强度：几秒内给出回答
ruby tools/pilota_ia.rb --sforzo medium --lingua inglese --modello claude-sonnet-5-5
ruby tools/pilota_ia.rb --motore api                     # 使用 API，需要密钥
```

## 照片与相册

行走时，按 **P**（可在 *系统 › 操作键* 中修改；手柄上为右肩键 RB）拍下视图的照片，不含准星和文字，并伴有闪光。如果正在录制路径，照片会归入该路径；否则归入单独的系列，每次进入该模式算一个系列。

当游览成为路径时，探索者会自己拍照：在到目前为止看到的目的地中最有趣的那些——当它的视线停留在上面且看到的尺寸足够大时（很多目的地只是被看到而没有走到），或者到达时；偶尔出现的开阔空间；绝不在已经拍过照的地方再拍，每 8 秒最多一张（每次游览最多 30 张）。每张照片它都会写下**拍的是什么**（那个东西、有多大、有多远、周围有什么）以及**为什么**选它：迄今最有趣的、醒目的颜色、视野中没有类似的东西、细节丰富、从背景中凸显的轮廓、由许多部件组成的物体、一处景色。驾驶它的 AI 用 `snap`（它的“为什么”）和 `say`（“是什么”）来请求自己的照片。

照片保存在模型旁边的 `<模型>_foto/<日期和时间>/` 中，为 1600 px 的 JPG，附带 `galleria.json`；路径以相对于模型的方式保存文件夹，因此模型连同照片一起移动后仍能找到。对于从未保存过的模型，或无法在模型旁写入时，照片保存在 `%APPDATA%/DagaWASD/foto`。

在 *相机 › 路径* 中，每条路径在“视频”旁都有自己的 **📷** 按钮：显示照片数量，单击在浏览器中打开相册；如果路径没有照片则为灰色，单击会说明如何拍照。列表下方是不属于任何路径的系列（录制之外的照片、已删除的路径）。

相册是一个单独的页面，即照片文件夹中的 `galleria.html`，每次打开时以 SketchUp 的语言重新生成。照片是木桌上的拍立得，进入视野时会慢慢显影，每张都附有笔记卡：拍的是什么、为什么、谁拍的、指示视线方向的指南针以及时间。有两种浏览方式：

- **排成一行**：用滚轮、方向键、拖动，或底部的胶片条（缩略图）横向滚动。顶部是用铅笔画出的游览路线：带编号的照片及其所看方向的视锥、比例尺、北方、行进方向。角落里的小地图会跟随当前照片。AI 的评论写在便利贴上，贴在游览路线中对应的位置；最后是一张汇总卡，列出时长、行走距离和照片；
- **散放在桌上**：可以用鼠标（或手指，或方向键）拿起并移动照片，布局会保留到下次。*重新摆整齐* 会把它们重新排成行。

单击可放大照片，并可使用 *幻灯片放映*（一张接一张；空格键暂停）。如果照片来自多个作者（你、探索者、AI），可以用顶部的印章筛选。地址中的 `#3` 跳到第 3 张照片，`#3z` 直接放大打开。它可以干净地打印（照片及其笔记），离线也能使用，并可以连同文件夹一起发送给别人。

**编辑** 可以就地修改文字，字迹不变：图库和每张照片的标题、*是什么*、*为什么*、印章和 AI 的笔记；✕ 将照片移出图库（文件保留），↺ 再放回。SketchUp 的原文永远不会丢失：每段文字都能恢复原样。修改会立即保存在浏览器中；*保存到文件夹*（Edge、Chrome）会把它们写入照片旁的 `galleria_modifiche.json` 和页面本身，随文件夹一起带走。

## 两个安装包

`tools\crea_rbz.bat` 在 `dist\` 中生成：

- `dagawasd-<版本>.rbz`：完整版，包含 **Claude Code 桥接**（`lib/bridge.rb`），一个仅限本机的服务器，在你从面板开启之前保持关闭，Claude Code 通过它在打开的模型中绘图；
- `dagawasd-<版本>-warehouse.rbz`：不含桥接，用于 Extension Warehouse。没有 `lib/bridge.rb`，扩展程序照样可以运行。

## 开发

代码、注释和更新日志均为意大利语。

- `installa.bat` 将源代码复制到找到的每个 SketchUp 的 Plugins 文件夹中。
- `tests\run_tests.bat` 运行测试（Ruby，使用模拟的 SketchUp；面板在 Node 模拟的浏览器中运行）。
- `tools\controlla_warehouse.bat` 按 Trimble 的规则（rubocop-sketchup）检查安装包。
- 版本号只写在 `dagawasd.rb`（`VERSION`）中；每个版本在 `CHANGELOG.md` 中都有对应章节。
- 图标由 `pubblicazione/` 中的 SVG 生成：`tools\rendi_icone.bat` 会重新生成工具栏图标（`icons/`）和 Warehouse 页面的图标（`pubblicazione/icona_512.png`）。
- Extension Warehouse 页面（英文文本和给审核者的说明）位于 `pubblicazione/extension_warehouse.md`。
- 本 README 有多种语言（英文 `README.md`、`README.it.md`、`.es`、`.fr`、`.de`、`.pt`、`.nl`、`.sv`、`.pl`、`.cs`、`.ru`、`.ja`、`.ko`、`.zh`）：修改时需同步到所有语言。
- 在运行中的 SketchUp 里，开启桥接并在面板中开启“窗口和按键”（供 Claude Code 使用的工具，不会被安装）：
  - `tools\finestre.ps1` 能做到 Ruby 做不到的事：原生窗口、提示框、菜单、连同天空和云一起截取视图、模拟按键，以及在 3D 视图中的真实点击（例如双击球体）；
  - `tools\collaudo.rb` 实时测试面板的按钮和菜单、“删除”的确认，以及一直到最终窗口的视频导出；
  - `tools\schermate.rb` 在 `pubblicazione/schermate/` 中生成页面截图（1920×1080，需要至少这么大的屏幕）；
  - `tools\prova_fps.rb` 在 FPS 模式下行走和奔跑，并测量头部晃动。
