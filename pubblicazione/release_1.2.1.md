DagaWASD 1.2.1: Portuguese fixes.

Windows only, SketchUp 2023 or later. All changes are in
[CHANGELOG.md](https://github.com/Dagadam/dagawasd/blob/main/CHANGELOG.md) (in Italian).
For the new features of 1.2 (autonomous explorer, photos and gallery, list
of key positions, Thin cameras) see the
[1.2.0 release](https://github.com/Dagadam/dagawasd/releases/tag/v1.2.0).

## Fixes

- **Portuguese**: a few texts added in 1.2.0 used Brazilian forms in an
  interface written in European Portuguese. The *Thin cameras* button, its
  confirmation and its undo entry now say «Rarear câmaras» (was «Rarear
  câmeras»); the explanation of *Adaptive analysis* now uses «ecrã»,
  «grelha», «autónomo» and «fotogramas»; the numeric keypad hint says
  «rato» instead of «mouse».

Nothing else changes: if you don't use the interface in Portuguese, you can
skip this update.

## Which file should I download?

| File | For |
|---|---|
| **`dagawasd-1.2.1-warehouse.rbz`** | **Everyone.** This is the version you want. |
| `dagawasd-1.2.1.rbz` | Only if you use **Claude Code**: it also contains the *Claude bridge* (see the [1.0.0 release](https://github.com/Dagadam/dagawasd/releases/tag/v1.0.0)). |

Install from *Extensions › Extension Manager › Install Extension*, over the
previous version. Your settings live in `%APPDATA%\DagaWASD` and are kept.

## Em português

**Correções.** Alguns textos acrescentados na 1.2.0 usavam formas
brasileiras numa interface em português europeu. O botão *Rarear câmaras*
(antes «Rarear câmeras»), a sua confirmação e a explicação da *Análise
