SketchUp 用の拡張機能（Windows）：WASD とマウス、またはゲームパッドで、モデルの中を一人称視点で歩けます。

▶ デモ動画：https://youtu.be/w6xE86y7iEw?is=7Gh12tF7atE_N9_K

⬇ **ダウンロード**：[最新リリース](https://github.com/Dagadam/dagawasd/releases/latest)（すべてのバージョン：[Releases](https://github.com/Dagadam/dagawasd/releases)）

## できること

- **歩行**：慣性、走る、しゃがむ、ジャンプ、階段と坂。虚空に落ちても安全に地面へ戻ります。
- **物体の物理**：グループとコンポーネントはマテリアルに応じて落ち、跳ね、倒れます。蹴る、つかむ、投げることができます。
- **空と天気**：日付・時刻・場所に応じた太陽、月、星。雨、雪、雲、雷雨、地面に積もる雪。
- **パス**：歩きながらカメラを記録し、再生し、シーンや AVI 動画として書き出せます。モデルの中で位置（ズームの長さの矢印が付いた球と、構図の枠）を移動・回転して調整したり、一から作ったりできます。パネルでは各パスを開くと位置の一覧が表示されます。位置をクリックするか、その球をダブルクリック（または Enter）すると、見えている画面のプレビュー付きで設定が開きます。2 つの位置の間をクリックすると、現在のビューから位置を追加します。再生中は一覧で現在の位置が点灯します。「カメラを間引く」は、重なり合った球を 1 つにまとめ、その平均（位置、視線、ズーム）にします。ただし互いの視線の差が 45° 以内のものに限ります。
- **自律エクスプローラー**：カメラがシーンを見て、最も意味のあるものを選び、それを見ながら一歩近づき、また繰り返します。最後には歩いた道がパスになります。詳しくは下へ。
- **写真とギャラリー**：P で見ているものを撮影します。エクスプローラーは探索中の最も面白いものを自分で撮影します。各パスのギャラリーはブラウザーで開きます。テーブルの上のインスタント写真に、メモが添えられています。詳しくは下へ。
- XInput **ゲームパッド**、テンキーで見回すこともできます。
- 設定パネルは 36 言語に対応。

動作環境：Windows 上の SketchUp 2023 以降。Mac ではインストールはできますが起動せず、その旨を表示します。

- SketchUp の **Extension Warehouse**（署名済み版）から、または
- [最新リリース](https://github.com/Dagadam/dagawasd/releases/latest) の *Assets* から **`dagawasd-<バージョン>-warehouse.rbz`** をダウンロードし、*拡張機能 › Extension Manager › 拡張機能をインストール* からインストールします。もう一つのファイル `dagawasd-<バージョン>.rbz` には Claude Code 用ブリッジも含まれます（*2 つのパッケージ* を参照）。

## 自律エクスプローラー

ツールバーの目のボタン（または *拡張機能 › DagaWASD › 自律エクスプローラー*）：小さなウィンドウでプロファイル（性格、下記参照）と、探索をパスとして記録するかどうかを選べます。選択は次回のために記憶されます。矢印キーと Enter、またはプロファイルのダブルクリックで、すぐに出発します。探索中に同じボタンを押すと止まります。サイクルは **分析 → 地点を選ぶ → その地点を見ながら一歩近づく → 分析** です。

- **分析**：画面のグリッドを通る光線の「網膜」（`view.pickray` + `model.raytest`）が、各セルの距離、法線、面、オブジェクト、色を得ます。そこから顕著性を計算します：奥行きの境界、稜線、細部、色のコントラスト（Lab）、希少性、人の大きさのコンポーネントやグループ。大きな壁や床はほとんど重視しません。距離、視野の中心、新しさで重み付けします。
- **記憶**：視線がすでに見たもののボクセル、すでに歩いた場所（平面と高さの両方：上の階は新しいまま）、目標ごと・カテゴリーごとの飽き（ソファを 1 つ見たら、同じソファへの興味は薄れます）。そのため同じものに何度も戻りません。
- **見たものの地図**：徒歩では、体の高さを通る光線が 50 cm のセルの地図（階ごとに 1 枚）に、見えた床とその高さ（床、段、家具の天板）、当たった壁を記録します。用途は 2 つです：
  - **フロンティア**：見たものと一度も見ていないものの境目（ドアの向こう、角の裏）が目標「未探索のエリア」になり、そこへ行って中をのぞきます。プロファイルの「動きたい気持ち」に応じて、開けた空間と同じ重みを持ちます。注目マップでは床の上の紫の小さな四角です。
  - **計画された経路**：目標ごとに、地図上で（A*）目標が見える地点までの道を計画します。壁や家具を少し離れて回り込み、階段を上り（一段ずつなら可、テーブルやソファは不可）、プレイヤーの最大勾配までの坂を上り、行けるところはまっすぐ進みます。まだ見ていない場所では楽観的に試します。分析のたびに新しい地図で残りの経路を確認し、ふさがっていれば別の道を探します。3 秒ごとには必ず計画し直します（近道を見つけたかもしれないので）。ぶつかった場所は記録して再計算します。目標が何かの陰に隠れたり、経路が目標から離れたりすると、進む方向を見ます。進行中の経路は床の上の破線です。探索は分析と同じく少しずつ進めます。
- **一歩**：地点に向かい、障害物を回り込み、階段を上り、段差から落ちることはありません。物体全体が見える距離で止まり、それを見ます。空からのビューでは飛んで、見るものがある場所に着地します。
- **物の周りを回る**：物体に着いたとき、プロファイルが求めれば（*物の周りを回る*、度数：写真家 180°、好奇心旺盛 90°）、より開けた側から物体を見ながら周りを回り、複数の方向から見ます。道がふさがれば引き返します。そのあと立ち止まります。
- **ジャンプ**：道をふさぐ低い障害物（低い塀、柵、大きな段）で、短い回り道がない場合、向こうに着地できる面があれば飛び越えます。プレイヤーのジャンプ力と重力を使います（初期設定では足が 1.08 m 上がり、その高さの 85 % 未満のものを飛び越えます）。椅子やテーブルの上には決して飛び乗りません。プロファイルでオフにできます（「ゆっくり」はジャンプしません）。
- **体**：目の高さ、半径、段差（最大 25 cm）、ジャンプ、重力はプレイヤーと同じです（パネル › プレイヤー）。探索中に変更しても反映されます。
- **なめらか**：ブリッジのライブ構築と同じく、分析は Fiber としてフレームとフレームの間に少しずつ動きます。網膜はそのモデルでの光線 1 本のコストに応じて細かくも粗くもなります。*システム › パフォーマンス › 適応的な分析* を使うと、分析の頻度も空いている計算力に合わせて、1 秒あたりの最小値と最大値の間で変わります。歩みは遅くなりません。
- **操作**：Esc またはクリックで停止、右クリックで一時停止、「ほかを探す」、注目マップ、カラーの目。ホイールで速度。I で左上の情報行を表示・非表示。別のツールに切り替えると止まります。中ボタンでオービットすると一時停止し、カメラを置いた場所から再開します。
- **動けない？** 10 秒間に 75 cm 動かなければ（近くの目標の間で迷っている、角に閉じ込められているなど）、12 方向から逃げ道を探して数秒間進みます。徒歩で道がなく、モードが自動なら飛び立ちます。
- **最後に**、開始時に「パスを記録」をオンのままにしていれば、探索はパス（「探索 1」…）になります。パネルから見返したり、シーンや動画にしたりできます。

### プロファイル

エクスプローラーの性格は**プロファイル**、つまり係数の組み合わせです：*拡張機能 › DagaWASD › 探索者のプロファイル…*、または探索中に右クリック › *プロファイル*（その場で切り替え）と *プロファイルを編集…*。

| プロファイル | 性格 |
|---|---|
| バランス | いつもどおり |
| 好奇心旺盛 | すぐ飽きて、細部や珍しいものを探し、よく探索し、物の周りを 90° 回る |
| ランナー | 3.2 m/s、素早い反応、短い立ち止まり |
| ゆっくり | 0.5 m/s、長い立ち止まり、ゆっくり動く視線 |
| 写真家 | 近づく前に目標をズームで拡大し、それから近づいて 180° 回る |
| 気まま | 気まぐれに選び、すぐに考えを変え、開けた空間が好き |
| 兵士 | 偵察、常に徒歩：3.6 m/s、遠くから短く見て、まだ見ていない場所を優先する |

ウィンドウでは各係数にスライダー（ドラッグ中、そのプロファイルを使っていればエクスプローラーがリアルタイムで変わります）と、元の値に戻す ↺ があります。グループ：移動（速度、停止距離、段差、徒歩/飛行）、視線（回転、反応、**視線の連続性** —— 見ているものの隣にあるものへ移ることをどれだけ好み、すでに目をそらしたものに戻らないか）、注意（立ち止まり、物の周りを回る、長さ、**決意** —— 選んだばかりの目標について何秒間考えを変えないか —— と**忠実さ**）、好奇心（記憶、飽き、動きたい気持ち、気まぐれ）、惹かれるもの（オブジェクト、シルエット、細部、色、希少性の重み）、ズーム。「新規」は使用中のプロファイルをコピーします。既定のプロファイルも変更でき、あとで元に戻せます。

`settings.json` では：`"explore_profile"`（使用中のもの）、`"explore_profiles"`（自作のもの、および既定のものへの変更）、`"explore_record"`（開始ウィンドウのパス記録のチェック）。値は層になって重なります：既定値（`EX_DEFAULTS`、`lib/explore.rb`）← `"explore": { … }` ← プロファイル ← 起動した側のオプション（ブリッジ）。

ブリッジをオンにすると、Claude Code がこれを操作・観察できます（開発ツールのコマンドはイタリア語です）：

```
ruby tools/esplora.rb avvia --secondi 120 --velocita 1.3   # 開始：120 秒、1.3 m/s
ruby tools/esplora.rb avvia --profilo Fotografo    # この探索だけのプロファイル
ruby tools/esplora.rb profili                      # 一覧。「profilo 名前」で使用中にする
ruby tools/esplora.rb segui --foto esplorazione    # 選択ごとに 1 行と写真 1 枚
ruby tools/esplora.rb ferma                        # 停止してパスを保存
```

### AI が運転

`pilota` と `guida` では、どこへ行くかを Claude Code が決め、エクスプローラーは自分で歩き、見続けます（`lib/expilot.rb`）。見えたものにはそれぞれ短く安定した名前があります（`o12` はオブジェクト、`s7` は面、`F3` は未探索のエリア）。AI が目的地を予定に入れ、エクスプローラーは自分の歩み、壁を回る道、自分の視線で順にたどり着きます。予定が空になると、また自分で選びます。AI を待って止まることはありません。

```
ruby tools/esplora.rb pilota                       # 通知を待ち、見えているものを説明する
ruby tools/esplora.rb guida --vai o12 --giro 90 --commento "主祭壇" --vai F3
ruby tools/esplora.rb guida --guarda o7 --per 3    # 動かずに振り向いて見る
ruby tools/esplora.rb guida --piace label:colonna=2 --evita o4
ruby tools/esplora.rb guida --sostituisci --punto 12,4,1.7   # 新しい予定：メートル単位の地点
ruby tools/esplora.rb guida --svuota               # 予定なし：また自分で選ぶ
ruby tools/esplora.rb guida --foto                 # 今の（または次の）立ち止まりで写真を 1 枚
ruby tools/esplora.rb guida --foto-sempre          # 立ち止まるたびに写真（--foto-mete：AI の目的地だけ、--senza-foto）
```

`pilota` を起こす通知：目的地に到着、目的地を完了（または断念とその理由）、予定がほぼ空・空、到達できない目的地、初めて見る注目すべきもの、写真。

**徒歩：どこまで行けるか。** 歩いているとき、説明には、エクスプローラーが見て作った地図に基づき、各物と未探索エリアについて到達できるか（`reach`：はい、未見のエリアを通ればたぶん、いいえ）と何メートル歩くか（`walk_m`）が書かれます。徒歩で行けないものへの「行け」は理由付きですぐに拒否され、写真ではそれらに薄い灰色のラベルが付きます。Stromboli では、自律パイロットが 1 分あたりの到達目的地を約 1 から 3 に増やしました。

**ラベル付きの写真。** AI の目的地の前で立ち止まると、エクスプローラーは静止して目的地を見たままビューの画像（800 px）を撮り、見えるもの全ての横に短い名前を書きます：目的地は黄、オブジェクトは青、面は灰、未探索のエリアは紫。こうして AI は「Group2577#2」などが何なのかを見て、名前で指し示せます。写真は `%APPDATA%\DagaWASD\pilota`（最新 40 枚）にあります。写真 1 枚につき、ビューの画像 1 枚分の時間（大きなモデルで約 0.5 秒）SketchUp が止まるため、静止中だけ撮ります。

ブリッジ側：`GET /explore/percept?since=N`（説明と通知）、`GET /explore/wait?since=N&timeout=60`（同じ説明ですが、起こすべき通知があるときだけ応答するので `pilota` は問い合わせ続けません）、そして `{"cmd": "steer", …}` を付けた `POST /explore`。

**動画の中のコメント。** AI の発言（`--commento`、`--di`、または steer の `say`）は、言った瞬間の位置に記録されたパスに残ります。シーンを作るときは最も近いシーンの説明になり、動画の横には `.srt` 字幕ファイルができます（AVI：同じ名前でプレイヤーが自動で開きます。PNG 画像：`crea_video.bat` が MP4 に入れます）。

**自律パイロット。** `tools/pilota_ia.rb` は 1 回ずつのコマンドなしで自分で運転します。ブリッジの通知を待ち、立ち止まった場所の説明と写真を Claude に送り、Claude の決定をブリッジに渡します。既定のエンジンは Claude Code 自身（`claude -p`、このパソコンのアカウント：キー不要）。`ANTHROPIC_API_KEY` が設定されていれば Claude API（`anthropic` gem）を使います。Stromboli では 1 ターン 4〜5 秒です。ターンごとにコストがかかるので、`--turni`（20）と `--secondi`（300）で上限を決め、最後に使ったトークン数を表示します。

```
ruby tools/esplora.rb avvia --a-piedi                   # 徒歩で開始
ruby tools/pilota_ia.rb --turni 15 --secondi 240        # 低い労力：数秒で応答
ruby tools/pilota_ia.rb --sforzo medium --lingua inglese --modello claude-sonnet-5-5
ruby tools/pilota_ia.rb --motore api                     # API を使う（キーが必要）
```

## 写真とギャラリー

歩いているとき、**P**（*システム › 操作キー* で変更可能。ゲームパッドでは右のバンパー RB）で、照準も文字もないビューの写真をフラッシュ付きで撮ります。パスを記録中なら写真はそのパスに入り、そうでなければ別のシリーズに入ります（モードに入るたびに 1 シリーズ）。

探索がパスになるとき、エクスプローラーは自分で写真を撮ります：それまでに見た目的地のうち最も面白いもの（視線がとどまり十分大きく見えたとき —— 多くの目的地は着かずに見るだけです —— または到着したとき）、ときどき開ける空間。すでに撮った場所からは撮らず、8 秒に 1 枚まで（1 回の探索で最大 30 枚）。各写真には、**何が**写っているか（そのもの、大きさ、距離、周りにあるもの）と、**なぜ**選んだか（それまでで一番面白い、目立つ色、似たものが見えない、細部が多い、背景から浮かび上がるシルエット、多くの部品でできた物、眺め）を書きます。運転する AI は `snap`（理由）と `say`（何か）で自分の写真を頼みます。

写真はモデルの横の `<モデル>_foto/<日付と時刻>/` に 1600 px の JPG として、`galleria.json` とともに保存されます。パスはモデルからの相対フォルダーを記憶するので、モデルを写真ごと移動しても見つけられます。一度も保存していないモデルや、モデルの横に書き込めない場合は `%APPDATA%/DagaWASD/foto` に保存されます。

*カメラ › パス* では、各パスの「ビデオ」の横に **📷** ボタンがあります。写真の枚数が表示され、クリックでブラウザーにギャラリーが開きます。写真がなければ灰色になり、クリックすると撮り方を説明します。一覧の下には、どのパスにも属さないシリーズ（記録外の写真、削除したパス）があります。

ギャラリーは 1 枚のページ、写真フォルダーの `galleria.html` で、開くたびに SketchUp の言語で作り直されます。写真は木のテーブルの上のインスタント写真で、視界に入ると現像され、それぞれにメモカードが付いています：何か、なぜか、誰が撮ったか、視線の方向を示すコンパス、時刻。見方は 2 通りです：

- **一列に**：ホイール、矢印キー、ドラッグ、または下のフィルム（サムネイル）で横にスクロールします。上部には鉛筆で描いた探索の道筋があります：番号付きの写真と見ていた方向の円錐、縮尺、北、進行方向。隅の小さな地図が現在の写真を追います。AI のコメントは道筋の該当する位置の付箋に書かれ、最後には所要時間、歩いた距離、写真をまとめたカードがあります。
- **テーブルに散らして**：写真をマウス（または指や矢印キー）で取って動かせます。配置は次回まで保たれます。*きれいに並べ直す* で列に戻ります。

クリックで写真を大きく開き、*スライドショー*（1 枚ずつ。スペースで停止）も使えます。複数の撮影者（あなた、エクスプローラー、AI）の写真があれば、上部のスタンプで絞り込めます。アドレスの `#3` は 3 枚目の写真へ、`#3z` はそれを大きく開きます。きれいに印刷でき（写真とメモ）、オフラインでも動き、フォルダーごと人に送れます。

## 2 つのパッケージ

`tools\crea_rbz.bat` は `dist\` に次を作ります：

- `dagawasd-<バージョン>.rbz`：完全版。**Claude Code 用ブリッジ**（`lib/bridge.rb`）を含みます。ローカル専用のサーバーで、パネルからオンにするまでオフのままです。Claude Code はこれを通じて開いているモデルに描画します。
- `dagawasd-<バージョン>-warehouse.rbz`：ブリッジなし、Extension Warehouse 用。`lib/bridge.rb` がなくても拡張機能はそのまま動きます。

## 開発

コード、コメント、変更履歴はイタリア語です。

- `installa.bat` は見つかったすべての SketchUp の Plugins フォルダーにソースをコピーします。
- `tests\run_tests.bat` はテストを実行します（Ruby、SketchUp をシミュレート。パネルは Node でシミュレートしたブラウザーで）。
- `tools\controlla_warehouse.bat` は Trimble のルール（rubocop-sketchup）でパッケージを確認します。
- バージョン番号は `dagawasd.rb`（`VERSION`）にだけあります。各バージョンには `CHANGELOG.md` に専用のセクションがあります。
- アイコンは `pubblicazione/` の SVG から作られます：`tools\rendi_icone.bat` がツールバーのアイコン（`icons/`）と Warehouse ページのアイコン（`pubblicazione/icona_512.png`）を作り直します。
- Extension Warehouse のページ（英語のテキストと審査担当者へのメモ）は `pubblicazione/extension_warehouse.md` にあります。
- この README は複数の言語であります（英語の `README.md`、`README.it.md`、`.es`、`.fr`、`.de`、`.pt`、`.nl`、`.sv`、`.pl`、`.cs`、`.ru`、`.ja`、`.ko`、`.zh`）。変更はすべてに反映してください。
- 起動中の SketchUp で、ブリッジをオンにし、パネルで「ウィンドウとキー」をオンにすると（Claude Code 用のツールで、インストールはされません）：
  - `tools\finestre.ps1` は Ruby が届かないところに届きます：ネイティブウィンドウ、警告、メニュー、空と雲を含むビューのキャプチャ、キー入力のシミュレーション、3D ビューでの実際のクリック（たとえば球のダブルクリック）。
  - `tools\collaudo.rb` はパネルのボタンとメニュー、「削除」の確認、最後のウィンドウまでの動画書き出しをライブでテストします。
  - `tools\schermate.rb` はページ用の画像を `pubblicazione/schermate/` に作ります（1920×1080。少なくともその大きさの画面が必要）。
  - `tools\prova_fps.rb` は FPS モードで歩いたり走ったりして、頭の揺れを測ります。
